Custom font for invitation titles and names
===========================================
1. Confirm that the font license permits use as a public webfont.
2. Copy one file into this folder as display.woff2 (recommended),
   display.otf, or display.ttf. Prefer the smallest suitable format.
3. Deploy the file. In /studio, open the content settings, find the
   typography controls, select the custom font for titles and names,
   then publish the configuration.
4. Check the cover, hero, section headings, and couple photo frames on mobile.

If no suitable font file is available, use the built-in Cookie font. Body text
remains Quicksand; the custom option changes only title and name lettering.
